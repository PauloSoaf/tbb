# Design system

O TBB usa uma interface sóbria, densa e responsiva. Tokens CSS definem superfície, texto, borda, ação, sucesso e perigo; dark mode preserva contraste.

Panels agrupam uma pergunta ou ação. Stat cards exibem números comparáveis. Empty states explicam o próximo passo. Formulários usam rótulo visível, erro textual e estado pending. Cor nunca é o único indicador.

Analytics usam Bklit por padrão, encapsulado em componentes do produto para manter formatação e semântica consistentes. O heatmap responde frequência, o funil responde conversão e os gráficos financeiros respondem fluxo e ritmo de gasto.

FinanceDataGrid mantém cabeçalho sticky, densidade compacta, seleção visível, navegação por teclado, drafts destacados e confirmação explícita para blocos. Ledger e Sheet compartilham a mesma fonte de dados.
